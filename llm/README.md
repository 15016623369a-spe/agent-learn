## 运行

沿用 Conda `fde`，本次核验 Python 3.11.16；本课只使用标准库，无需安装依赖、API Key 或模型文件。

在仓库根目录执行：

```bash
conda activate fde
python -B llm/lesson01.py
python -B -m llm.lesson01
```

编辑器直接运行 `llm/lesson01.py` 时选择 `fde` 解释器。程序没有项目内导入，不依赖额外的路径注入。
