## 作业三：无效输入与任务不存在

| 情况 | HTTP | 进入 execute_task | 创建记录 |
|---|---|---|---|
| 缺少字段 | 422 | 否 | 否 |
| 未知任务类型 | 422 | 否 | 否 |
| 纯空白需求 | 422 | 否 | 否 |
| 查询不存在的编号 | 404 | 否，进入查询路由 | 否 |

三类输入错误发生在路由前的校验阶段，本例不生成业务请求编号。404 在路由中发生，有 X-Request-ID 响应头。字符串长度限制先于 strip 的后置校验，新接口三个任务统一采用 requirement、1–1000 字符；Lesson03 原接口约定不变。

## 作业四：内存生命周期

刷新浏览器不重启服务，已有记录可继续查询；应用进程重启或 reload 后字典重新为空，原编号查询返回 404。Git 管理磁盘文件及历史，运行期字典不会自动写回源文件，也不会自动上传到 GitHub。跨重启保存记录需要把 store.py 的内存实现替换为数据库或其他持久化存储。

本次自动检查在父进程创建记录后，启动全新 Python 子进程，确认子进程无法读取该记录；并未将其描述为重新观测了用户浏览器刷新和 Uvicorn 重启操作。

## HTTP 与任务执行状态

任务创建后执行失败，仍按本课约定返回 HTTP 201，task.status=failed，失败原因保存在 error_code / error_message。查询这一失败任务返回 HTTP 200。HTTP 404 表示没有记录；HTTP 422 表示输入校验失败。任务内 error_code=504 不等于这次 HTTP 响应为 504。
