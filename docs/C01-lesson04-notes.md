## 四项作业与理解

1. 保存写入工作区；git add 暂存当前内容；git commit 形成本地版本；git push 同步提交到远端。一个课程项目使用同一个仓库，无需每个文件单独绑定 GitHub。
2. git status --short 的第一列是暂存区相对上次提交的状态，第二列是工作区相对暂存区的状态。为显示空格，下面用 · 代替空格：

```text
·M notes.md  修改尚未暂存
M· notes.md  修改已经暂存
MM notes.md  已暂存后又修改
AM notes.md  新文件已暂存后又修改
```

git diff 比较工作区与暂存区；git diff --staged 比较暂存区与上次提交。暂存后继续修改，直接提交只记录已暂存版本；需要再次 add 才包含最新修改。
