# C04 Lesson08 · 办公分析输入输出综合实践

任务契约检查时间范围、金额口径、数据来源和部门分组。缺来源、单位冲突和查询未执行分别提前返回 `needs_info`、`needs_clarification` 和 `awaiting_query`。

查询成功时，预算按包含当前课提示、契约和上下文的最终消息计数。总预算 1050、预留 120 时，输入从 949 降至 525 个 Token，移除 H02 后保留 D01 与 T01。必需资料仍超限时返回 `over_budget`。引用用发送版本的索引核验。

成功报告需要金额字段、空的待补列表和必要引用。金额先和 T01 核对，展示随后用 T01 的整数分渲染。格式错误可修正一次并重新验证。金额不匹配时返回 `totals_mismatch`，报告停止生成。

七条课堂路径包含缺来源、单位冲突、等待查询、超限、正常报告、修正后成功和金额不符。固定数据得到运营部 83.05 元、销售部 125.00 元。Token 用本地分词器实测，业务输入和响应来自教学样例。 [四题答案](C04-Lesson08-homework.md)
