# C04 Lesson06 · 输出校验与失败处理

校验按 JSON 解析、Schema、请求内的业务依据依次进行。某层失败时返回该层结果。代码复用前课的报告 Schema 和来源索引，在 Schema 副本中增加必填的 `department_totals_fen`。它可为 `null` 或以分为单位的部门金额对象，值为非负整数。

通过结构校验后，先检查全部引用编号是否存在。金额字段有值时，要求应用持有的 T01 查询已成功、候选金额与查询结果相同、引用列表含 T01。未知来源、查询未完成、金额不符和遗漏查询引用都有独立错误码。

课堂策略允许解析或结构错误请求一次修正。修正后的文本重新执行全部检查。修正仍失败或遇到业务错误时返回 `rejected`，同时令 `data` 为 `None`。

课堂九条手写样例覆盖等待查询、修正成功、两种修正失败、未知引用、查询未完成、金额不符、漏引查询和金额一致。核对范围覆盖结构化金额，任意自由文本的事实仍需在展示层单独处理。业务金额可以从通过核对的字段生成，缺失时用固定文案。
